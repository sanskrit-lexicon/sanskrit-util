## 🧠 Dev Notes & Hypotheses

- **`slp1_to_devanagari` is a REAL transcode, not a display replace.** It supplies the virāma between clustered consonants and picks independent-vowel vs mātrā by position. Its maps are **inverted from the same Devanāgarī→SLP1 maps `deva_to_slp1` uses** (kept in lock-step), so the pair is a true round-trip: `deva_to_slp1(slp1_to_devanagari(s)) == s` for canonical SLP1. Only the 3 marks are hardcoded (M→anusvāra, H→visarga, ~→candrabindu) because anusvāra and candrabindu both map back to `M` on the Deva→SLP1 side and can't be inverted unambiguously.
- **Two documented not-round-trip-stable cases** (they match `deva_to_slp1`'s own lossy behaviour, so they are excluded from the round-trip fixture): candrabindu (`~`→ँ→`M` anusvāra) and avagraha (`'`→ऽ, which `deva_to_slp1` drops). SLP1 accents (`/ \ ^`) pass through unchanged.
- **`slp1_simplify` was stranded.** It was pushed to `origin/feat/deva-to-slp1` + tagged `v0.2.0` but **never PR'd/merged**, because it was Python-only (no JS port / vectors / docs) — which violates the repo's parity contract. PR #11 recovers it AND completes it to contract.
- **Versions were stale at 0.1.0** in all three of `pyproject.toml` / `package.json` / `__init__.py` even though the CHANGELOG documented an (unreleased-on-`main`) 0.2.0. PR #11 bumps to **0.3.0** consistently and the CHANGELOG's `Unreleased` SLP1 content is promoted into the 0.3.0 section.
- **`ṁ` (U+1E41)** was already handled by `to_slp1` (`→M`); PR #11 just adds golden-vector + unit-test coverage. This is the named blocker for dropping `sanscript` from SamudraManthanam's IAST→SLP1 path.
- Round-trip fixture [`vectors/slp1_roundtrip_sample.txt`](https://github.com/sanskrit-lexicon/sanskrit-util/blob/feat/slp1-to-devanagari/vectors/slp1_roundtrip_sample.txt) = 1000 real MW `<k1>` headwords (canonical-SLP1-only filter), sampled deterministically from csl-orig `mw.txt`; regenerate with the scratch extractor if `mw.txt` changes. `tools/gen_vectors.py` runs the round-trip + the SLP1-set donor lock on every regen (both skip gracefully if the sibling repos are absent).
